Đắk Lắk Travel AI

1. Sơ đồ Quy trình Vận hành (Operational Flow)

Mô tả vòng đời khi người dùng yêu cầu AI lên lịch trình hoặc Chatbot

sequenceDiagram
    autonumber
    actor User as Khách du lịch
    participant UI as Giao diện Web (Frontend)
    participant Server as Web Server (PHP)
    participant DB as Database (MySQL)
    participant AI as Gemini AI API

    User->>UI: Truy cập web & Chọn "Lên lịch trình / Chatbot"
    UI->>Server: Gửi yêu cầu (Thông tin sở thích, số ngày...)
    
    rect rgb(235, 248, 255)
    Note right of Server: Khâu chuẩn bị Dữ liệu (RAG)
    Server->>DB: Truy vấn danh sách điểm đến, giá vé...
    DB-->>Server: Trả về dữ liệu thô (JSON/Array)
    Server->>Server: Đóng gói dữ liệu thực tế vào System Prompt
    end

    Server->>AI: Gửi Prompt (Dữ liệu web + Yêu cầu User)
    AI-->>Server: Trả về kết quả phân tích (Lịch trình / Câu trả lời)
    
    Server->>UI: Trả kết quả (Render HTML / Cập nhật UI)
    UI-->>User: Hiển thị lịch trình trực quan / Tin nhắn

2. Sơ đồ Luồng dữ liệu tổng quan (Data Flow Architecture)

Mô tả cách các thành phần trong hệ thống kết nối và trao đổi dữ liệu

graph TD
    Client(Trình duyệt Khách hàng)
    
    subgraph Frontend [Frontend - Giao diện]
        UI[Trang web HTML/CSS]
        JS[JavaScript & 360 Viewer]
    end
    
    subgraph Backend [Backend - Xử lý]
        PHP[PHP Core & Router]
        SSE[Realtime Stream]
    end
    
    subgraph Database [Database & Storage]
        MySQL[(Cơ sở dữ liệu MySQL)]
        Files[(Thư mục Ảnh/360)]
    end
    
    subgraph External_APIs [Third-party APIs]
        Gemini[Google Gemini AI]
        OAuth[Google / Facebook Auth]
        GoogleMaps[Google Maps API]
        OpenMeteo[Open-Meteo API]
    end

    Client <-->|Click, Nhập liệu| UI
    Client <-->|Xoay, Kéo thả 360| JS
    
    UI <-->|HTTP Requests| PHP
    UI <-->|Kết nối liên tục| SSE
    
    PHP <-->|Truy vấn PDO| MySQL
    PHP -->|Đọc file| Files
    SSE <-->|Check tin nhắn mới| MySQL
    
    PHP <-->|Gửi/Nhận Prompt JSON| Gemini
    PHP <-->|Xác thực Token| OAuth
    PHP <-->|Lấy Thời tiết| OpenMeteo
    
    JS <-->|Render Bản đồ| GoogleMaps
    UI <-->|Chuyển hướng Login| OAuth
